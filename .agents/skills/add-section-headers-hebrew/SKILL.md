# Add Section Headers in Hebrew (Code Commenter)

Use this skill whenever the user asks to add section headers or comment banners into a source code file (e.g., "הוסף כותרות לקוד", "הוסף הערות חלקים לקובץ", "חלק את הקוד לחלקים עם כותרות", "add section headers", "/add-section-headers-hebrew").

---

## 1. Workflow Steps

### שלב 1: קריאת הקובץ וניתוח לוגי

1. קרא את כל תוכן קובץ הקוד במלואו.
2. זהה את החלקים הלוגיים המרכזיים של הקובץ לפי סדר הופעתם:
   - ייבוא מודולים, ממשקים וטיפוסים
   - קבועים והגדרות מערכת
   - משתני מצב בזיכרון (State Management)
   - פונקציות עזר (Utility / Helper Functions)
   - פונקציות ליבה ועיבוד (Core Functions)
   - מאזיני אירועים, אתחול וריצה ראשונית (Listeners & Init)

### שלב 2: תבנית הכותרת המדויקת (סגנון א׳)

כל כותרת תתווסף כהערה ממוסגרת בקווי `═` כפולים (באורך 59 תווים), עם מספור רציף **החל מ-1**:

```typescript
// ═══════════════════════════════════════════════════════════
// [1] יבוא מודולים והגדרת טיפוסים
// ═══════════════════════════════════════════════════════════
```

**דוגמאות לכותרות תקניות:**

```typescript
// ═══════════════════════════════════════════════════════════
// [1] יבוא מודולים והגדרות טיפוסים
// ═══════════════════════════════════════════════════════════

// ═══════════════════════════════════════════════════════════
// [2] קבועים ומשתני מצב מקומיים
// ═══════════════════════════════════════════════════════════

// ═══════════════════════════════════════════════════════════
// [3] פונקציות עזר לחילוץ מידע
// ═══════════════════════════════════════════════════════════

// ═══════════════════════════════════════════════════════════
// [4] סריקת דף ואיסוף נתונים
// ═══════════════════════════════════════════════════════════

// ═══════════════════════════════════════════════════════════
// [5] מאזיני אירועים ואתחול ראשוני
// ═══════════════════════════════════════════════════════════
```

## 2. כללי בטיחות ועבודה

1. **זיהוי כותרות קיימות ובקשת אישור לדריסה:** במידה ובקובץ הנבחר כבר קיימות כותרות חלקים (למשל הערות עם `// ═` או `// [...]`), חובה לשאול מפורשות את המשתמש:
   > _"זוהו כותרות חלקים קיימות בקובץ. האם ברצונך להחליף ולדרוס את הכותרות הקיימות?"_  
   > אין להחליף או להוסיף כותרות מעל כותרות קיימות ללא אישור מפורש מהמשתמש.
2. **אפס שינוי בלוגיקה:** אין לשנות, להזיז או למחוק אף שורת קוד קיימת. הפעולה מוסיפה אך ורק שורות הערה ורווחים קלים להפרדה ויזואלית נקייה.
3. **רווחים:** השאר שורת רווח ריקה אחת מעל כל באנר כותרת, ושורת רווח אחת (או שורה צמודה להצהרה) מתחתיו לפי המבנה המקובל בקוד.
4. **בקשת אישור מפורש:** לפני עריכת הקובץ בפועל, תאר למשתמש את רשימת החלקים והכותרות שבחרת להוסיף, ובקש אישור מפורש ("אשר" / "המשך" / "כן").
